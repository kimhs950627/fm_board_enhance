### 뇌하수체/시상하부 질환

1) 뇌하수체 기능 저하
  - Sheehan syndrome: 산후 출혈로 인한 뇌하수체 허혈성 괴사, 피로, 저혈압, 무월경, 질 위축, 치모 감소 등의 다발성 호르몬 결핍 증상 나타남 → 치료: 스테로이드, HRT

### 뇌하수체 전엽 질환

- 프로락틴 분비 뇌하수체 선종: 고프로락틴혈증, 치료: bromocriptine → 임신하면 중단
- 말단비대증(Acromegaly) : 손목터널증후군(양손이 저림), 얼굴 변화, 목소리 변화, 당뇨
- 선별검사: IGF-1 / 확진검사: 경구당부하검사

### 뇌하수체 후엽 질환

  - 요붕증 (Diabetes insipidus): 다뇨, 야뇨, 갈증, 다음
- 진단: 24hr 소변량 > 40mL/kg, 소변 삼투질농도 < 300 mOsm/kgH2O
- 감별진단: 위 진단 만족 후, 아래 검사 중 하나 시행 (최근엔 첫번째 방법 선호.. 수분제한 위험할 수 있어서)
  - SIADH (항이뇨호르몬 부적절 분비 증후군):
- 폐 소세포암 병력, 중증 저나트륨혈증 (Na+<135mEq/L) + 저삼투혈증 + 부종 없음 + 소변 나트륨 배설 증가 (urine Na+>20mEq/L)
- 치료: 수분 제한 + 고장성 식염수(중증 시) + 바소프레신 길항제 (Tolvaptan 등)

### 갑상선 질환


### 갑상선 기능저하증

- 피로, 체중 증가, 서맥, 저체온증, 변비, 탈모, 우울감, 비함요 부종(non-pitting edema)
- TSH 증가, Free T4 감소, 중추성은 TSH와 Free T4 모두 감소
- 치료: Levothyroxine
협심증, 부정맥 등 심혈관환자에서 25ug 소량 시작, 4-6주 간격 증량
  - 임신중 갑상선 기능저하증: levothyroxine 증량
  - 약 복용을 잊었을 때: 생각나는 즉시 1알 복용 (2알 한번에 복용 금지)
  - 갑상선 호르몬 대치요법 도중 발생한 협심증: Propranolol (갑상선호르몬이 심장 산소 소모 증가시킴)

### 점액부종 혼수 (Myxedema coma)

- 갑상선 기능저하증 치료받지 않은 상태에서 저체온, 저혈압, 의식저하가 발생하는 응급 질환
- 저혈압, 서맥, 저체온, 저나트륨혈증, 저혈당, 호흡억제 등 동반 가능
- 치료: 고용량 Levothyroxine (IV), IV Hydrocortisone 병행

### 갑상선 기능항진증

- 체중 감소, 더위 민감성, 빈맥, 손 떨림, 불안
- 항진증 정도가 심할수록 재발 위험 높음
- 검사: Tc-99m 갑상선 스캔 (결절, 염증, 항진증, 그레이브스 병 평가)
- 항진증 증상 + T4정상, TSH감소 →  T3 검사 (r/o T3 Toxicosis)
- 치료: 항갑상선제 (메티마졸(MMI), PTU), 방사성 요오드 치료, 증상완화 BB, 수술 등
- 용량 조절 지표 : T4 / 중단 결정 지표 : TSH
- MMI, PTU 복용 부작용: 무과립구증 (CBC 검사, ANC<1500 일 때), 발진, 가려움 (항히스타민제 투여)
  → 무과립구증 발생 시 항갑상선제 즉시 중단 (중단하면 거의 대부분 돌아옴)
- 항생제 (Piperacillin-tazobactam 또는 Cefepime 필요시 Vanco)

### 그레이브스병

- 항진증의 가장 흔한 원인
- 혈액 검사: TSH 저하, Free T4/T3 상승, TSH receptor antibody(TSHR Ab, TR Ab) 양성
- 방사성 요오드 섭취율(RAIU): 섭취율 증가 (정상: 10~20%)

### 항진증의 상황별 치료

- 갑상선 중독선종 (Toxic adenoma): Radioactive ablation (hot nodule 제거)
- 항갑상선제요법 불순응, 수술 후 재발: Radioactive iodine (RAI)
- Thyrotoxicosis 합병증: Hypokalemia (하지마비) - 치료: β-blocker
- 임신중 갑상선 기능항진증: 항갑상선제 감량 (PTU 쓰다가 2분기부터 MMI)

### 산후 갑상선염 (Postpartum Thyroiditis)

- 출산 후 1년 이내
- Anti-TPO 항체(+), RAIU 감소, 갑상선 압통 없음
- 치료: 증상 조절 (두근거림 심하면 - Propranolol)

### 하시모토 갑상선염 (Hashimoto disease)

- 특별한 증상 없이 갑상선만 미만성으로 커짐
- Anti-TPO 항체 (+), TSH 증가 (FT4, T3는 정상이었다가 점차 감소), RAIU 감소, 갑상선 압통 없음
- 갑상선기능저하증 있으면 치료 시작

### 아급성 갑상선염 (Subacute thyroiditis)

- 바이러스 감염 발생(감기) 후 항진증
- 치료: NSAIDs (Naproxen), 증상조절 안되면 steroid (Prednisone)

### Sick euthyroid syndrome

- 급성 질환에 의한 cytokine 증가로 hormone level 변화 생김, 주로 T4 정상, TSH 정상, T3 감소
- 치료: 특별한 치료 필요 없이 기저 질환 치료가 우선

### 갑상선 결절/갑상선 암

- 갑상선 수술 후 발생한 손발저림, 입주변 감각 이상, 의식 저하
→ 부갑상선 기능 저하에 의한 저칼슘혈증 가능성 → 이온화 칼슘 검사
- 갑상선 결절 평가 알고리즘 : TSH 정상, 증가 → 초음파 / TSH 감소 → 갑상선 스캔
- FNA atypia 나오면 재검
### 부신질환


### 부신피질 질환

- 쿠싱증후군
- 중심성 비만, moon face, 성욕감퇴, 피부 얇아짐, 자색선조, 멍 잘 듦, 고혈압, 당뇨, 다모증...
- 선별검사: 24시간 소변 유리 코르티솔 → 증가
야간 1mg 덱사메타손 억제 검사 → 억제 안됨
Midnight plasma (or salivary) cortisol test
  - 확진검사: Low-dose dexamethasone suppression test
  - 원인에 따라 치료 (쿠싱병: 수술, 약물), 스테로이드 점진적 감량 (수술 전)
### 일차성 알도스테론증

- 고혈압, 저칼륨혈증 → 근력 저하, 다뇨, 대사성 알칼리증
- 선별검사: 혈장 알도스테론/레닌 활성도 비율(ARR) > 20
- 확진검사: 생리식염수 부하 검사 → 알도스테론 억제 안됨
- 부신 CT로 종양 확인
- 치료: Spironolactone, Eplerenone (알도스테론 길항제),  수술적 절제 (편측성 종양)
### 부신기능저하증 (Adrenal insufficiency)

- 저혈압, 피로, 체중 감소, 색소침착(멜라닌 증가, 손발이 검게), 저나트륨혈증, 고칼륨혈증, 대사성 산증
- 검사: Rapid ACTH stimulation test → 코르티솔 반응 없으면 부신 기능 부전
- 하이드로코르티손 (코르티솔 보충), 플루드로코르티손 (알도스테론 보충)

### 부신수질 질환

  - 갈색세포종
- 발작성 고혈압, 두통, 심계항진, 발한 (3대 증상), 공황발작 유사 증상, 체중 감소, 고혈당
- 검사: 24시간 소변 catecholamine (메타네프린) → 카테콜아민 증가
- 부신 MRI/CT or MIBG scan
- 수술 전 알파차단제(phenoxybenzamine, doxazosin) 후 베타차단제 투여, 수술적 절제 (부신 종양 제거)

### 당뇨


### 당뇨병 진단

① 공복혈당 (Fasting Plasma Glucose, FPG) ≥ 126mg/dL
- 최소 8시간 이상 금식 후 채혈한 혈당이 126mg/dL 이상이면 당뇨병 진단
- 공복혈당 100~125mg/dL → 공복혈당장애(IFG, Impaired Fasting Glucose)
② 경구포도당부하검사 (OGTT) 2시간 후 혈당 ≥ 200mg/dL
- 75g 포도당 복용 후 2시간째 측정한 혈당이 200mg/dL 이상이면 당뇨병
- 140~199 mg/dL → 내당능장애(IGT, Impaired Glucose Tolerance)
③ 당화혈색소 (HbA1c) ≥ 6.5%
- 장기간 혈당 조절 상태를 반영하는 검사, 5.7~6.4% → 당뇨 전단계 (Prediabetes)
- HbA1c가 낮게 나오는 상황: 용혈성 빈혈, 최근 수혈, 임신, 만성 신질환(투석), 철결핍성 빈혈
- HbA1c가 높게 나오는 상황: 철결핍성 빈혈 치료 중, 비타민 B12 결핍, 비장절제 후
④ 무작위 혈당 (Random Plasma Glucose, RPG) ≥ 200 mg/dL + 당뇨병 증상
- 다뇨(polyuria), 다음(polydipsia), 설명되지 않는 체중 감소 등의 당뇨 증상이 있는 상태에서 언제든지 측정한 혈당이 200mg/dL 이상이면 당뇨병
  → 공복혈당, OGTT, HbA1c 중 하나라도 기준을 초과하면 다른 날 한 번 더 재검하여 확진
  → 단, 무작위 혈당 + 당뇨 증상이 있는 경우 재검 없이 즉시 당뇨병 진단 가능
  → 두 검사가 모두 전단계 범위면 재검 간격을 1년보다 짧게(3~6개월) 잡고 위험인자를 함께 평가함
  → 당뇨병 전단계는 연 5~10%가 당뇨병으로 진행함
  → 공복혈당 118 + HbA1c 6.3 처럼 양쪽이 모두 전단계면, 한쪽만 기준을 넘겨도 당뇨병으로 올리지 않음
  - C-peptide: T1DM 감소(<0.6 ng/mL), T2DM 약간 증가(1.0-1.2 ng/mL)

### 당뇨병 치료

- Metformin
- 간에서 포도당 생성 억제, 말초 인슐린 감수성 개선
- 체중변화 없음, 저혈당 없음, 당화혈색소 1.0-2.0% 감소 / 안정형 만성심부전 사용 가능
- 금기: 중증 간, 신장애 (eGFR<45)
- 부작용: 젖산산증, 소화장애, vitamin B12(cobalamin)결핍
- SGLT2 inhibitors: - flozin (Dapagliflozin(포시가), Empagliflozin(자디앙), Ipragliflozin(슈글렛))
- 신장에서 포도당 재흡수 억제
- 체중 감소, 저혈당 없음, 당화혈색소 0.5-1.0% 감소
- 금기: 투석, eGFR<45 (약제별 다름), 고령, 신장애 (용량조절)
- 부작용: 요로, 생식기 감염, 케톤산증
- DPP-4 inhibitors: - gliptin (Sitagliptin(자누비아), Gemigliptin(제미글로), Linagliptin(트라젠타))
- 인크레틴(GLP-1, GIP)증가, 포도당 의존 인슐린 분비 증가
- 체중변화 없음, 저혈당 없음, 당화혈색소 0.5-1.0% 감소
- 부작용 적음
- 금기: 심부전 (임상경험없어 권장되지 않음), (vildagliptin - 간기능 저하시 권장되지 않음)
- GLP-1 receptor agonists: - (lu)tide (Liraglutide(빅토자,삭센다), Semaglutide(오젬픽,위고비))
- 포도당의존 인슐린 분비 증가
- 체중 감소, 저혈당 없음, 당화혈색소 0.8-1.5% 감소
- 금기: 갑상선 수질암 과거력, 가족력, 췌장염(주의)
- 부작용: 위장관 장애
- Sulfonylurea: - ide (-zide, - pride, -amide) (Glimepiride(아마릴), Gliclazide(디아미크롱))
- 췌장 베타세포 인슐린 분비 촉진
- 체중 증가, 저혈당 있음, 당화혈색소 1.0-2.0% 감소
- 금기: 중증 간기능, 신기능 환자
- 부작용: 저혈당
- Meglitinides : - glinide (Repaglinide, Neteglinide, Mitiglinide)
- 췌장 베타세포 인슐린 분비 촉진
- 체중 증가, 저혈당 있음(but 위험 적다.. 혈당강하작용 신속, 작용시간 짧음), 당화혈색소 0.5-1.5% 감소
- 식사 불규칙한 사람 혈당조절에 유용 (반감기 짧아서)
- 금기: 중증 간기능 장애
- Thiazolidinedione (TZD): - zone (Pioglitazone(액토스), Lobeglitazone(듀비에))
- 인슐린 민감성 개선
- 체중 증가, 저혈당 없음, 당화혈색소 0.5-1.4% 감소
- 금기: 심부전
- 부작용: 골절, 부종, 심부전 악화
- α-glucosidase inhibitors : - bose (Acarbose, Voglibose)
- 위장관에서 다당류 흡수 억제
- 체중 변화 없거나 감소, 저혈당 없음, 당화혈색소 0.5-1.0% 감소
- 금기: 소화장애 동반 만성장질환, 중증 간,신장애 (eGFR<25)
- 부작용: 위장관 장애
- 체중감소: SGLT-2 억제제, GLP-1 receptor agonist
- 체중증가: SU, meglitinides, TZD
- 저혈당유발: SU
- HbA1C 9%이상, Sx (+) 로 처음 진단받은 환자 > 인슐린
- B형 간염환자 : TZD(Pioglitazone) (DPP-4 i 중 vildagliptin은 간기능 저하시 금기라서)
- 신기능 저하: DPP-4 i(Linagliptin), TZD(Pioglitazone)
- 간기능 저하+ 체중증가: DPP-4 i(Sitagliptin)
- TZD(Pioglitazone) 부작용: 체중증가, 부종, 골절, 심부전
- 경구혈당강하제 복용 해외출장: 현지시간 맞추어 복용
인슐린투여 해외출장: 4시간 이상 시차 → 동쪽 : ⅔로 감량, 서쪽: 용량유지
  - 인슐린 장기투여 중 잦은 저혈당 발생 원인?: 당뇨병성 신증 (신기능 저하>인슐린 배설지연>저혈당 발생)
  - Metformin > B12(Cobalamin) 결핍 > 말초신경병증 (발저림증상)
  - 당뇨 + 단백뇨(>300mg/g): 신장 보호 목적의 ACEi(Enalapril)/ARB 사용

### 당뇨병의 합병증: 급성 합병증

  - Diabetic ketoacidosis (DKA)
  - 원인: 인슐린 부족, 감염, 스트레스, 스테로이드, 심한 탈수
  - 혈당: 250~600 mg/dL
  - 케톤 증가, pH < 7.3, HCO3- < 18 mEq/L (대사성 산증), 혈장 삼투압 정상 또는 약간 증가
  - 증상: 다음, 다뇨, 탈수, 구토, 복통, kussmaul respiration, 아세톤 냄새(과일향)
  - Hyperosmolar hyperglycemic state (HHS)
  - 원인: 감염, 탈수, 이뇨제, 스테로이드, 급성질환(뇌졸중, 심근경색 등)
  - 혈당: 600 mg/dL 이상
  - 케톤증, 산증 거의 없음, 혈장 삼투압 > 320 mOsm/kt (고삼투성)
  - 증상: 극심한 탈수, 의식저하, 발작, 신경학적 이상
  → 치료: 수액 보충 (0.9% NS → 혈당 200-250mg/dL 도달하면 5% dextrose solution)

### 이상지질혈증

- 스타틴 복용 후 근육 증상이 생기면 먼저 CK와 갑상선기능(TSH)을 확인함. 횡문근융해(CK > 10배, 갈색뇨, 급성 신손상)가 아니면 약을 끊기보다 원인 평가 후 재시도하는 것이 원칙임
- 기출 맥락: 스타틴을 시작한 지 6주 된 환자가 "허벅지가 뻐근하다"고 호소하는 형태로 반복 출제됨
  - 함정 1: 근육 증상만으로 바로 중단하는 것 → 대부분은 nocebo이거나 다른 원인(갑상선기능저하, 비타민 D 결핍, 운동)임
  - 함정 2: CK를 보지 않고 "정상 범위"라고 단정하는 것 → 기저 CK가 없으면 비교 기준이 없음
- statin 복용중 LFT 상승: 3배 미만이면 유지, 3배 이상이면 중단 후 재평가 > 지속되면 교체
- 스타틴 간독성: ALT > 3배 + 증상, 또는 > 5배면 중단함. 근육 증상과 별개로 평가함

### 스타틴 근육 증상(SAMS)

| 단계 | 할 일 | 판단 기준 |
|---|---|---|
| 1 | 증상 양상 확인 | 근력 저하·전신 근육통·갈색뇨 여부 |
| 2 | CK 측정 | 정상 상한의 4배 미만 / 4~10배 / 10배 초과 |
| 3 | 이차 원인 배제 | TSH, 비타민 D, 신기능, 병용약 |
| 4 | 조치 결정 | 아래 표 |

| CK | 증상 | 처치 |
|---|---|---|
| 정상~4배 | 경미 | 유지 또는 감량, 4주 후 재평가 |
| 4~10배 | 중등도 | 일시 중단 → 증상 소실 후 저용량 또는 다른 스타틴으로 재시도 |
| >10배 | 있음 | 즉시 중단, 수액·신기능 확인, 횡문근융해 평가 |
| >10배 | 없음 | 반복 측정으로 확인 후 개별 판단 (운동·외상 원인 흔함) |

- 스타틴 휴약 후 재투여로 인과관계를 확인함. 증상이 재현되면 SAMS로 봄
- 재시도 시에는 친수성 스타틴(로수바스타틴, 프라바스타틴) 또는 저용량 + 비스타틴 병용(에제티미브)을 고려함
- 고강도 스타틴이 꼭 필요한 2차 예방 환자에서는 SAMS를 이유로 치료를 완전히 포기하지 않음
- 시험 포인트: "스타틴 중단"이 정답인 경우는 CK > 10배이거나 횡문근융해 소견이 동반될 때뿐임
- 피브레이트 병용: 근육 독성 위험이 커짐. 특히 gemfibrozil 병용은 피함
- 갑상선기능저하: 스타틴 근육 증상을 악화시키는 대표적 이차 원인임. TSH를 반드시 봄
